# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainer can see the report.

Don't open a public issue, discussion or pull request for a vulnerability.

Include what's affected, how to reproduce it and what an attacker could do with it.

## What to expect

This is a personal project maintained in spare time. You'll get an acknowledgement within a week, and updates as the fix progresses. Once a fix is released, the advisory is published with credit to you, unless you'd rather stay anonymous.

## Supported versions

Only the latest release, or the default branch where there are no releases, gets security fixes.
